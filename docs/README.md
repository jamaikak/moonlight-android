# Documentation

This is a personal fork of [Artemis Android](https://github.com/ClassicOldSong/moonlight-android), itself a fork of Moonlight Android. The upstream feature list and build notes are in the [root README](../README.md). This folder covers what this fork adds and how to build and install it.

- [Fork changes](fork-changes.md): features added on top of upstream
- [Building and CI](building.md): local builds, the GitHub Actions workflow, installing the APK
- [NVIDIA Shield with a DualSense controller](shield-dualsense-guide.md): stop the PS button leaving the stream and still send Guide to the host
